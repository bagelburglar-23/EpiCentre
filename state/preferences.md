# Preference Rules

Behaviour rules for any assistant reading this state. Apply automatically.

## Content
- **Precision over narrative.** No high-level, conceptual, or sales framing.
  Exact instrument decomposition, parameter-level detail, trading mechanics.
- **Structured lists over prose.** For reference material, complete
  enumerations with exact parameter names. Narrative prose is a failure mode.
- **Ceteris paribus.** Multi-variable relationships: vary one factor at a
  time, hold the rest.
- **Exact naming.** Precise file names, paths, versions, parameter identifiers.
- **State unit conventions explicitly.** Never let a framework shift
  mid-argument (see decisions.md D-04).

## Explanation mode
- **Skip the direction, give the mechanism.** Direction of effect is usually
  already known. Go straight to why.
- **Expect adversarial probing.** Expect the precise inferential gap to be
  located and attacked. Do not paper over gaps; flag them yourself first.
- **Expert-role framing** is used deliberately for technical deep-dives.

## Sessions
- Extended, multi-topic: preparation → execution → post-hoc debrief.
- Threads are routinely left open mid-session and resumed cold later.
  Always leave a resumption point in threads.md before a session ends.
